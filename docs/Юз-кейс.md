## Полный перечень функциональных требований (Use Cases)

### 0. Общие системные функции (сквозные)
- **Аутентификация и авторизация** – вход по логину/паролю, разграничение доступа по ролям.
- **Регистрация** – создание учётной записи с выбором роли (Соискатель / Работодатель).
- **Восстановление пароля** – отправка ссылки для сброса пароля на электронную почту.
- **Логирование действий** – запись в лог-файл всех важных событий: вход/выход, создание/изменение/удаление объектов, отклики, ошибки.
- **Система уведомлений** – push-уведомления в реальном времени (через сокетное соединение) для каждой роли:
  - Соискателю: при появлении новой вакансии с рейтингом совпадения ≥50%.
  - Работодателю: при новом отклике на его вакансию.
  - Администратору: при регистрации нового пользователя, при добавлении вакансии (можно настраивать).

---

### Роль: Гость (неавторизованный пользователь)
1. **Просмотр общих вакансий** – доступен список всех активных вакансий без персонализации.
2. **Фильтрация и поиск вакансий** – по городу, зарплате, типу занятости, ключевым словам.
3. **Регистрация в системе** – выбор роли (Соискатель или Работодатель), заполнение соответствующей формы.
4. **Вход в систему** – переход в авторизованную зону.

---

### Роль: Соискатель (User)
#### Управление профилем
5. **Заполнение и редактирование анкеты**:
   - Имя, фамилия, дата рождения (или возраст), город, номер телефона, email.
   - Дополнительная информация (образование, опыт, проекты).
   - Логин и пароль (может менять).
6. **Управление тегами навыков** – выбор из общего справочника тегов, которые характеризуют его компетенции (для построения рекомендаций).
7. **Просмотр своего профиля** – отображение всех данных.

#### Работа с вакансиями
8. **Персонализированная лента рекомендаций** – список вакансий, отсортированный по проценту совпадения тегов пользователя с тегами вакансии. Вакансии с совпадением ≥50% помечаются специальным образом (например, значком).
9. **Просмотр всех вакансий** – полный список с возможностью сортировки (по дате, зарплате).
10. **Новые вакансии** – вкладка с вакансиями, добавленными за последние 24 часа.
11. **Расширенный фильтр** – фильтрация по зарплате, городу, типу занятости, требуемым тегам.
12. **Детальный просмотр вакансии** – полная информация, включая описание, требования (теги), контакты работодателя.
13. **Добавление вакансии в избранное** – сохранение для быстрого доступа.
14. **Отклик на вакансию** – отправка заявки работодателю. Система проверяет, не откликался ли пользователь ранее на эту же вакансию.
15. **Просмотр истории откликов** – список отправленных заявок с указанием статуса (на рассмотрении, приглашение, отказ).
16. **Просмотр истории просмотров** – недавно открытые вакансии, никакой функции, просто просмотр.
17. Жалоба на вакансию с указанием причины, будет рассмотрено администратором.

#### Аналитика для соискателя
17. **Анализ зарплат по рынку** – график/диаграмма средних зарплат по вакансиям, соответствующим его тегам, с фильтром по периодам (неделя, месяц, год).
18. **Тренды навыков** – список наиболее востребованных тегов среди всех вакансий за выбранный период (в виде рейтинга).
19. **Геоаналитика** – распределение вакансий и зарплат по городам (если указан город).

#### Уведомления для соискателя

20. Получение уведомлений о новых вакансиях с процентом совпадения ≥50%.
21. Приветственное (После регистрации: краткое руководство, предложение заполнить профиль)
22. Напоминание о незаполненном профиле (Если пользователь не указал теги или город через день после регистрации).
23. Изменение статуса отклика
24. Вакансия из избранного закрыта

---

### Роль: Работодатель / HR (Employer)
#### Управление профилем компании
21. **Регистрация и редактирование профиля компании**:
    - Название организации, контактное лицо (имя, фамилия), номер телефона (опционально), email, логин, пароль.
    - Дополнительная информация о компании (сайт, описание).

#### Управление вакансиями
22. **Создание новой вакансии**:
    - Заголовок, описание, город, зарплатная вилка, тип занятости.
    - Выбор тегов (требования к навыкам) из общего справочника.
    - Публикация (вакансия становится активной).
23. **Редактирование / закрытие / удаление своей вакансии** (только своих).
24. **Просмотр списка своих вакансий** с краткой статистикой (количество просмотров, откликов).
25. Просмотр всех вакансий, без возможности откликнуться.

#### Работа с кандидатами
25. **Просмотр откликов на свои вакансии** – список откликнувшихся соискателей по каждой вакансии.
26. **Управление статусами откликов** – изменение статуса (принято в работу, приглашение на собеседование, отказ). При изменении статуса соискатель получает уведомление.
27. **Просмотр профиля соискателя** – анкета, его теги, история откликов.

#### Аналитика для работодателя
29. **Конверсия вакансий** – график: сколько просмотров → откликов → приглашений по каждой вакансии.
30. **Сравнение зарплат** – средняя зарплата по аналогичным вакансиям в системе (по тегам).
31. **Анализ конкурентности** – соотношение количества соискателей с нужными тегами к количеству открытых вакансий по этим тегам.
32. **Геоаналитика для HR** – распределение соискателей по городам.

#### Уведомления для работодателя
33. Мгновенное уведомление о новом отклике на любую из его вакансий.
34. Ваша вакансия популярна (Количество просмотров вакансии превысило среднее по аналогичным в 2 раза).
35. Изменение статуса отклика соискателем (Соискатель подтвердил или отклонил приглашение на собеседование).
36. Зарплата сильно отличается от рынка рынка (При создании/редактировании вакансии система сравнивает вилку со средней по похожим вакансиям и выдаёт предупреждение, если она значительно ниже, не в уведомлениях а при редактировании/создании).

---

### Роль: Администратор (Admin)
#### Управление пользователями
34. **Просмотр всех пользователей** (соискателей и работодателей) с возможностью фильтрации по роли, дате регистрации.
35. **Блокировка / разблокировка пользователя** – при блокировке пользователь не может войти в систему, блокировка на определенный срок либо навсегда.
36. **Удаление пользователя** (пометка как удалённого, а не каскадное удаление связанных данных).
37. **Создание нового администратора** – добавление учётной записи с правами администратора (логин и пароль задаются администратором).

#### Модерация вакансий
38. **Просмотр всех вакансий** (активных и неактивных).
39. **Удаление вакансии** при нарушении правил.
40. **Просмотр жалоб**.

#### Управление справочниками
41. **Добавление новых тегов** (навыков) в общий список. Удаление тегов запрещено (только деактивация, чтобы не сломать связи).
42. **Просмотр списка тегов** с частотой использования.

#### Системная аналитика (дашборд администратора)
43. **Общая статистика системы**:
    - Количество пользователей (с разбивкой по ролям).
    - Количество активных вакансий.
    - Количество откликов за период.
44. **Графики активности**:
    - Регистрации по дням/месяцам.
    - Публикации вакансий по дням.
45. **Топ-10 тегов** по использованию в вакансиях и резюме.
46. **Аналитика по городам** – где больше всего вакансий и соискателей.

#### Уведомления для администратора(2 вкладки)
Не важное:
47. **Уведомление о регистрации нового пользователя**.
48. **Создании новой вакансии**.
Важное:
49. **Жалоба на контент**
50. **Ошибка сервера** (Критическая ошибка в логах через Logback).
51. **Подозрительная активность**(Обнаружено > 10 откликов с одного пользователя за минуту, или массовое создание вакансий).
